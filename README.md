# 🤖 ติดตั้ง Claude บน Chrome

ส่วนเสริม (Extension) ที่ให้ Claude **มองเห็นและใช้งานเบราว์เซอร์ Chrome แทนคุณได้** — คลิก พิมพ์ กรอกฟอร์ม เปิดเว็บ และทำงานซ้ำ ๆ ให้อัตโนมัติ

---

## ✅ สิ่งที่ต้องมีก่อน

- บัญชี Claude แบบเสียเงิน: **Pro, Max, Team หรือ Enterprise**
- ใช้ได้เฉพาะ **Google Chrome** เท่านั้น (เบราว์เซอร์อื่นและมือถือใช้ไม่ได้)

---

## 📥 ขั้นตอนติดตั้ง

1. เปิด **Google Chrome** แล้วไปที่ Chrome Web Store
2. ค้นหาคำว่า **Claude** (หรือเปิดลิงก์ติดตั้งด้านล่าง)
3. กดปุ่ม **“Add to Chrome”** เพื่อติดตั้ง
4. **เข้าสู่ระบบ** ด้วยบัญชี Claude ของคุณ
5. **ปักหมุดไอคอน** → กดรูปจิ๊กซอว์ 🧩 มุมขวาบน แล้วกดหมุด 📌 ข้างคำว่า Claude
6. **กดอนุญาตสิทธิ์ (Allow)** ให้ Claude ใช้งานเบราว์เซอร์ได้

🔗 **ลิงก์ติดตั้ง:** https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn

---

## 🚀 เริ่มใช้งาน

- กดไอคอน **Claude** บนแถบเครื่องมือ → จะเปิดแถบด้านข้าง (Side Panel) ค้างไว้ขณะเล่นเว็บ
- พิมพ์สั่งงานเป็นภาษาคนได้เลย เช่น
  - “นัดประชุมใน Google Calendar”
  - “สรุปอีเมลใน Gmail ให้หน่อย”
  - “ช่วยแก้เอกสารใน Google Docs”
- Claude รู้จักวิธีใช้ **Slack, Gmail, Google Calendar, Google Docs และ GitHub** อยู่แล้ว สั่งสั้น ๆ ได้เลย

---

## ⚠️ ข้อควรระวัง

- ฟีเจอร์นี้ยังเป็น **รุ่นทดลอง (Beta)** — ใช้อย่างระมัดระวัง
- ให้สิทธิ์เฉพาะเว็บที่ **คุณไว้ใจและคุ้นเคย** เท่านั้น
- คอยดูสิ่งที่ Claude ทำเสมอ อย่าปล่อยให้ทำงานสำคัญ (เช่น จ่ายเงิน) โดยไม่ตรวจสอบ
